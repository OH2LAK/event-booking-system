Run your ham radio meeting without the spreadsheet

Registration and accommodation booking for radio amateur gatherings and any event with rooms, camper vans and tents. Guests book, see live availability and get a priced confirmation. You run it all from a browser.

Why organisers like it

A hotel weekend with 60 radio amateurs has the same hard parts every time. They are solved here.

🏨

Accommodation done properly

Rooms of any size, people joining an existing room with a booking reference, camper vans, tents, single beds and day visitors. Availability updates as people book.

🧮

Prices calculate themselves

Room, extra nights, meal package, optional extras and meeting fee add up to a total that guests see before they book and that is kept in the confirmation.

🌍

20 languages, your currency

Guests switch language with one click. Prices are in your currency and guests can see an approximate amount in theirs.

📋

Ready for the venue

Hotel list, check-in desk and printable slips come from the same data as the registration. No re-typing on arrival day.

🛡️

Privacy built in

Consent at booking, an opt-in public guest list, per-person export and erasure, retention reminders and a verified "erase everything" for after the event.

🔑

You own it

Your server and your data. Three runtime dependencies, no trackers or analytics, no build step. One Docker command starts it.

What is in the box

Everything below is configured in the browser. No code changes are needed to run your own event.

Booking types

Rooms, camper van spots, tent spots, organizer-assigned single beds and day visitors who pick their days. Optional solo use of a double room.

One-day events

Switch the event to a one-day event and the form becomes a plain registration: no accommodation, just who is coming and what they want to join.

Optional extras

Dinner, an excursion, a workshop: guests tick what they want. Each extra has its own price, capacity and sign-up deadline, and you see how many to order.

API and webhooks

Connect other systems: read counts and bookings, export CSV or JSON, make bookings from your own web shop or register, and get signed webhook messages when bookings change. Keys with separate permissions.

Your own domain

Hosted events can use your own address, for example ilmo.yourclub.fi, for an extra fee. One DNS record from you, the certificate is automatic.

Payment status

Show prices and how to pay (for example at the door) and mark bookings paid as money arrives. Online payment is not built in yet.

Event structure

Event days, optional extra nights such as a Thursday night, rooms booked for the whole event or per night, and an optional meal package.

Registration control

Open and close by hand or by date, an announcement banner, a closed message, and a secret bypass link for late registrants.

Emails

Confirmation to the guest, notification to the organizer, and updates when a booking or its accommodation changes.

Booking admin

Live dashboard, sortable bookings table, edit any booking, change accommodation with the price difference worked out, CSV export. One password for the whole team.

Event setup

Details, branding, structure, room types, prices, currencies and translations. A separate password keeps a helper from breaking the event.

Currencies

One native currency for payment plus display currencies with approximate conversion. Rates by hand or from the European Central Bank.

Translations

English, Finnish, Swedish, Norwegian, Danish, Icelandic, Estonian, Latvian, Lithuanian, Polish, German, Spanish, Portuguese, Italian, French, Dutch, Greek, Ukrainian, Czech and Hungarian. Plain JSON files, easy to improve on GitHub.

Who is coming

An opt-in public page with callsign, first name and the kind of stay, only for guests who agreed.

Try it. Break it.

The live demo is a fictional event with ten fake bookings. Book a room, open the admin, change the prices, delete the whole event. It rebuilds itself every night and after a quiet period.

Run your own event

You need a server with Docker. Then:

git clone https://github.com/OH2LAK/event-booking-system.git
cd event-booking-system
cp .env.example .env          # set your passwords
docker compose up --build -d

Open /?setup=1, describe your event, and share the booking page. The README covers installation, HTTPS and passwords, and the guides cover the admin, languages, currencies and data protection.
